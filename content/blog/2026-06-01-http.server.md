```bash
$ cd # to your directory of choice

$ python3 -m http.server 
```

that's it. that's the whole trick.

---

No more burning CDs (other than bootable ones), no more making USBs
(other than bootable ones).

No more memorizing what ssh option to disable certain crypto, either!

No samba auth shenanigans to go thru either

Use one of those Wi-Fi serial devices. Wi-Fi carts. 
Or better yet, built-in ethernet. `curl` exists on everything that runs
a command line. 

---

I've been using this trick to get libraries and packages to a Slackware 9.0
system on a Pentium 3 900MHz with shitty Trident Cyberblade graphics.
Works *shockingly* well with this sort of setup.

I previously used this for my various PowerBooks to good effect too. Even
over their mediocre Wi-Fi chips the download speed is pretty spiffy!

---

I know people who use this trick to stream video over their local network
via mpv. Honestly I really do respect these people. It Just Works.

---

If you want a "richer" version of this, I believe 
[copyparty](https://github.com/9001/copyparty) is a good step up from this.
It smartly degenerates back into the above case. But it's not as flashy as
"type this command in which I assure you already have."
